VigiaVia

Buracos detectados por visão computacional, priorizados para a zeladoria

1. Mostre o buraco

Limiar maior = menos alarmes falsos, mas pode perder buracos pequenos.
⚠ ATENÇÃO: BURACO À FRENTE

Use a câmera ou envie uma foto ou um vídeo de uma via.

No vídeo, use a barra para pausar, voltar ou avançar (no menu ⋮ do vídeo dá para reduzir a velocidade). Pausado, a análise mostra exatamente o quadro na tela.

2. Envie o relato

    Onde está o buraco?

    Toque no mapa ou arraste o marcador até o buraco.

    Privacidade: enviamos só o recorte da via onde está o buraco e o local marcado. Nenhuma foto inteira, nome ou dado do seu aparelho é guardado. A busca de endereço usa o Nominatim (OpenStreetMap).

    O botão libera quando um buraco é detectado. No vídeo, pause no buraco para enviar aquele quadro; com o vídeo rodando, vai o quadro em que ele apareceu com mais confiança.

    Fila priorizada

    Prioridade = severidade × (1 + log₂ confirmações). Só uma pessoa da zeladoria transforma o relato em ordem de serviço com Validar (IA com pessoa no circuito).
